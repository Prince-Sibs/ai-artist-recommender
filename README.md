# AI Artist Recommendation System

- This uses training data from [kaggle.com](kaggle.com)
- It check similarity scores between artists and provide ones with top scores

## Example

- Lets say user wants 2 similar artists for Eminem

1. Eminem vs Drake - 0.92 Score
2. Eminem vs BTS - 0.20 Score
3. Eminem vs Central Cee 0.89 Score

- The model will pick Drake and Central Cee

> **Note** This example does not use real data
